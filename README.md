### 👤 About Me

I'm a developer and student focused on mobile development with **Flutter and Dart**, with a background in native **Android (Kotlin and Java)** and systems programming in **C and C++**. I also build for the web with HTML, CSS and JavaScript, and I use **Python** for data work and machine learning, from regression models to small interactive apps. Right now I'm sharpening my app architecture skills, getting deeper into ML, and shipping projects that solve real, local problems.
